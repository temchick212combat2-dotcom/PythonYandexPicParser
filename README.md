# Парсер Яндекс Картинок

Профессиональный парсер для автоматического скачивания изображений из Яндекс Картинок по списку номенклатуры из Excel файла.

## 📋 Требования

- Python 3.8 или выше
- Windows / macOS / Linux
- Google Chrome браузер (последняя версия)
- Стабильное интернет-соединение

## 🚀 Установка

### 1. Установка Python

Скачайте и установите Python с официального сайта: https://www.python.org/downloads/

**Важно:** При установке обязательно отметьте галочку "Add Python to PATH"

### 2. Скачивание проекта

Скачайте все файлы проекта в одну папку или клонируйте репозиторий:

```bash
git clone https://github.com/yourusername/yandex-images-parser.git
cd yandex-images-parser
